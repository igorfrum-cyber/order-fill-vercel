## Жизненный цикл

`startApplication()` создаёт явный `context = {elements, state, actions}` на запуск. Фабрики получают его аргументом и возвращают функции. `elements` хранит DOM; `state` — прежние изменяемые значения; `actions` — собранные действия. Глобального singleton-контекста нет.

Поля state читаются живыми, а не копируются destructuring. Bootstrap сохраняет порядок заполнения elements/state, регистрации listener и начальных вызовов. Фабрики не выполняют раннюю DOM-инициализацию. Длинные регистрации перенесены в `ui/*/events.js`, вызовы регистрации остались в прежней последовательности.

Generation чтения цен, revision склада, отключение контролов пересчёта, snapshots правок, очистка object URL и проверки скачивания сохранены с владельцами. Их политика не менялась.
