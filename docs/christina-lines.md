# CHRISTINA: комплекты PROFF

## Область действия

Только профессиональные линии PROFF, в обычном режиме Тюмени и в «Севере». HOME использует обычный добор. Суммы HOME/PROFF независимы. Текущие ручные количества являются отправной точкой; рекомендации и прогноз не пересчитываются этой функцией.

Цены в скачиваемых бланках CHRISTINA остаются клубными. Количества меняются, формулы бланка сохраняются. Закупочная сумма на платформе учитывает основную скидку и скидку за комплекты, поэтому отличается от суммы бланка поставщику. Для других брендов прежняя выгрузка скидки сохранена. Акции не определяются и не суммируются с комплектной скидкой: расчет использует клубную цену и указанную основную скидку, без акционных надбавок к скидке.

## Формулы

Для каждой позиции i: P_i = ROUND(клубная цена_i * (1 - основная скидка / 100), 2).

Число полных комплектов M = MIN(Q_i) среди ВСЕХ обязательных артикулов линии. При M < 3 скидки нет. Количества поставщика кратны 3; вручную введенные количества не исправляются молча. Например, 18,18,18,3 дают 3 комплекта. Скидка действует на 3 единицы каждого артикула, а не на весь заказ.

```text
Стоимость без комплектной скидки = SUM(ROUND(P_i * Q_i, 2))
Дополнительная скидка = SUM(ROUND(P_i * M * 0.05, 2))
Стоимость закупки линии = Стоимость без комплектной скидки - Дополнительная скидка
```

Основная скидка 30%, затем 5%: комплектная единица стоит 0,70 * 0,95 = 0,665 клубной цены, а не 0,65. В Excel для одного товара: `=ROUND(B2*(1-$B$1/100),2)` (основная закупочная цена); для его комплектной скидки `=ROUND(C2*$H$1*5%,2)`, где H1 содержит число комплектов всей линии. Эти формулы поясняют платформу, но не подменяют клубные цены в бланке.

## Решение о доборе

1. Определить следующий уровень комплектов: 3,6,9,... Добавить только недостающие количества до него. Проверять весь шаг целиком.
2. Сначала линии с большим количеством A+, при равенстве A, затем B. Далее больше отношение дополнительной экономии к стоимости добавки.
3. Стоимость линии после шага не выше 130% ее закупочной стоимости перед началом текущего запуска. База не обновляется между шагами. Нулевая база не позволяет специальный добор линии.
4. Прирост комплектной скидки не меньше 15% стоимости добавленных товаров после основной скидки, но до комплектной скидки.
5. Покрытие после добавления: C <= 2 месяца + доставка; B <= 2,5 + доставка; A <= 3 + доставка; A+ <= 3,5 + доставка. Используется прогноз платформы, не простое среднее продаж. Общий предел 6 месяцев также соблюдается.
6. Итог после скидок не выше цели на 5%. Если шаг не проходит, не добавлять его частично ради комплекта.
7. Когда подходящие линии закончились, обычный добор по обеспеченности с действующими разрешениями.

Исключение: для первых 3 комплектов, когда отсутствует ровно один артикул, можно добавить 3 даже без продаж и сверх лимитов запаса. Ручной запрет/замок не обходится: менеджер должен снять его в предпросмотре. Пороги 30%, 15% и 5% остаются обязательными. Исключение не повторяется для перехода с 3 на 6 комплектов.

После достижения цели разрешено только это завершение первой тройки комплектов при одном отсутствующем артикуле. Если новая скидка понизила общую сумму ниже цели, обычный добор возобновляется. При уменьшении заказа применяется прежний порядок, но каждый пробный шаг заново оценивает скидку всей линии, включая ее потерю.

Пример: цены после основной скидки по 100 руб., заказ 18,18,18,3. До изменения: 5700 - 60 = 5640 руб. Добавка 3 к четвертому товару стоит 300 руб.; экономия увеличивается на 60 руб. (20% добавки). После: 6000 - 120 = 5880 руб. Рост 4,26%, шаг проходит денежные пороги, если позволяют покрытие и общая цель.

## Чтение бланка и код

- `christinaProffLines` в `workbookProcessor.js`: цветные непрерывные строки без артикула отделяют линии; «Профессиональный уход» не является линией. Разные fillId могут обозначать почти одинаковый цвет. Все артикулы сохраняются в обязательном составе, включая отсутствующие в отчете продаж.
- Подтвержденное исключение сентябрьского PROFF: Nuance без заголовка выделяется по началу названия товара. Раздел «ОБЩАЯ ЛИНИЯ», включая CHR133, исключен. В актуальном бланке 9 линий, 87 артикулов.
- `christinaLines.js`: чистые функции цены, комплектности, проверки атомарного шага и ранжирования. Неполные/дублирующиеся метаданные не дают скидку автоматически.
- `budgetPlanner.js`: проход по комплектам и обычный добор; стоимость пробного изменения считается по всему заказу. Снимок ручных количеств сохраняется для комментариев и отмены.
- `orderPricing.js`, `budgetDialog.js`, `app.js`: основная скидка, текущий итог, предпросмотр комплектов/экономии, применение. В «Севере» меняется только поставщик, не перемещения.
- `npm run test:christina`: арифметика, ограничения, исключения, замки, сокращение; при наличии оригинального бланка также структура линий и сохранность клубных цен. `test:budget` и `test:tyumen` проверяют общую регрессию.

Содержимое таблиц не исполняется как код. Исходные файлы пользователя в Git не включаются.
