# Модульная браузерная архитектура

Статус: действующий. Область: внутренний перенос. Проверено: 13 октября 2026 года.

Причина: два крупных файла объединяли несвязанные обязанности UI и обработки workbook.

Решение: сохранить браузер/Vite/Vercel и runtime-зависимости, выделить domain, Excel infrastructure, workflows и UI. Старые пути остаются фасадами; код/микросервисы Артема не переносить.

Последствия: один владелец каждой функции, прямые внутренние импорты, прежние mutation/copy semantics. Domain не получает DOM/XML; временная граница workbook-адаптера описана в [карте модулей](../architecture/modules.md).

UI использует явно передаваемый context с живым state/actions. Это сохраняет жизненный цикл без циклов между контроллерами и глобального singleton. Сборка и прежняя последовательность событий централизованы в bootstrap.

Контроль: immutable baseline до переноса, все ZIP-части, UI/скачивания, SHA тел, граф импортов и индекс. Добавлены только dev-инструменты проверок; новых пользовательских функций нет.
