# Изменение проекта

Статус: действующий. Область: разработка. Проверено: 13 октября 2026 года.

Начать с [карты модулей](../architecture/modules.md) и [продуктовых правил](../README.md). Проверить ветку и чужие рабочие изменения. В фасады логику не возвращать.

Бренд: обновить `domain/brands/rules.js`, quantity/budget rules, при необходимости Excel blanks. Добавить синтетический workbook и проверку количества, комментария, цены и экспортируемого файла. Обновить продуктовый документ.

Формула: изменить одного владельца domain и проверить пустое значение, ноль и округление. Адаптер применяет формулу и не содержит второй копии. Изменение поведения требует отдельного решения; baseline внутреннего переноса остаётся неизменным.

UI: соответствующие controller/events; bootstrap отвечает за сборку и порядок. Проверить shared state, generation/revision и object URL, ввод/ошибки/отмену/скачивание. Screenshot не заменяет взаимодействие.

Excel: существующие XML-примитивы, сохранность ZIP-частей, формул, стилей, связей, расширения и макрос-сегментов. Неопределённый остаток не превращать в ноль.

Перед review выполнить [полный gate](testing.md), проверить diff и индекс. Новое архитектурное решение записать в decisions; завершённый план маркировать завершённым.
