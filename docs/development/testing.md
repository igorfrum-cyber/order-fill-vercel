# Тестирование

Статус: действующий. Область: разработка и gate интеграции. Проверено: 13 октября 2026 года.

`npm run verify`: структура/ссылки, Тюмень, бюджет, CHRISTINA, baseline и build. Старые команды — алиасы перенесённых тестов. Полный gate: запустить `npm run dev -- --port 3210`, затем `npm run verify:full`. Другой адрес задаётся `TEST_URL`. Браузер: `npx playwright install chromium` или `CHROME_PATH`. Playwright/pngjs и eslint-scope — только dev-зависимости; runtime не менялся.

## Baseline

`tests/parity/baseline.json` рассчитан исходным commit `1e2baa1354c40156ff8f559ad5b2f2d27e119a0e` до переноса. Сравниваются экспорты, отчёты, рекомендации, правки, цены, Тюмень с продажами и без них, Север, пересчёт, бюджет и все распакованные ZIP-части побайтно. Игнорируются только метаданные контейнера ZIP, не XML, значения, типы, формулы, стили, диапазоны, отношения или имена частей. Тюмень дополнительно проверяет неизменность входов.

`tests/parity/ui/` — исходные desktop/mobile состояния четырёх режимов, заполненные отчёты и preview. E2E проверяет бюджет apply/undo, запрет скачивания без комментария, оба фактических северных файла после правки и подавление устаревшего результата склада при смене файла/бренда. Все имена и ZIP-части сравниваются с исходником. Ожидания скачиваний регистрируются до клика; подменённый File.arrayBuffer управляется явным release, а не sleep.

Для каждого screenshot точно сравниваются DOM-тексты, классы, геометрия, radii, значения, hidden/disabled/checked и имена скачиваний. Время, viewport, scale, browser/version, шрифт, язык, timezone фиксируются в `environment.json`; hover/focus нормализованы. Визуальный gate требует этого же окружения, а не произвольной ОС/версии Chromium. HTML/CSS также защищены SHA.

RGBA сравниваются без масок. Измеренные на исходнике вариации разрешены только в пределах двух пикселей от реальных геометрических границ округлённых элементов и нативных checkbox/radio; текст и внутренние области не подпадают под допуск. Лимиты: максимум 100 отличающихся пикселей на весь screenshot, связная область максимум 12 пикселей, отклонение каналов максимум 16/255. Только два изолированных пикселя границы могут отличаться сильнее, максимум 48/255: исходник сам показал два таких пикселя на углу кнопки, delta38. DOM при этом обязан совпасть точно. Эталоны не обновлялись.

Выполнено три baseline-self и три refactor-baseline запуска в одном окружении; все прошли. Максимумы по запуску (пиксели / delta): baseline `22/38`, `5/38`, `5/3`; refactor `78/38`, `55/7`, `5/38`. Каждый изменённый пиксель прошёл геометрическую проверку; сильных пикселей не больше двух. Подробные логи: игнорируемый `test-output/ui-review/`.

Воспроизведение: `node scripts/prepare-ui-reference.mjs`, затем запустить `npm run dev -- --port 3213` из `test-output/ui-reference`. Модульная версия должна работать на 3212. `BASELINE_URL=http://127.0.0.1:3213/ TEST_URL=http://127.0.0.1:3212/ CHROME_PATH=... node scripts/verify-ui-repeats.mjs` выполняет шесть проверок и сохраняет распределение отличий. Capture новых эталонов откажется работать на refactored server; существующие файлы не перезаписывает.

Fixtures синтетические. `Macros.xlsm` содержит непрозрачный синтетический macro-сегмент/customXml для проверки сохранности ZIP. Это не полная проверка исполняемых реальных макросов или Excel-приложения. `tests/integration/legacy-input.mjs` генерирует BIFF8 XLS и сравнивает конвертацию, явный ноль и отказ запрещённого legacy-бланка с loader из исходного commit; XLSX/XLSM проверяются на сохранение исходного объекта bytes. Реальная legacy-книга остаётся дополнительной приватной проверкой.

`node tests/parity/replay-baseline.mjs` извлекает исходник из Git в игнорируемый test-output и воспроизводит контрольные сценарии без обновления эталонов. Workbook, бюджет и цены внедряются явно и все берутся из исходного commit; текущий check использует текущих владельцев. История baseline должна быть доступна. Capture отказывается перезаписывать baseline; расхождение требует расследования, а не обновления ожидаемого результата.

## Приватные проверки

`npm run test:private` либо `test:workbook` запускает `tests/private/workbook.mjs`, которому нужны Downloads-файлы из его списка. На baseline проверка завершилась ENOENT обязательного `агио артикул.xlsx`. Отсутствие файла — неуспех и ограничение, не зелёный пропуск. Основной gate автономен. Пользовательские книги и результаты не коммитятся.

`verify:structure` проверяет фактический граф, циклы, границы domain, внутренние импорты фасадов, SHA тел workbook-функций, неизменность HTML/CSS/Vercel, локальные ссылки и индекс документов. Исторический архив и redirect явно исключены из индекса действующих материалов.
