# Тестирование

Статус: действующий. Область: разработка и gate интеграции. Проверено: 14 октября 2026 года.

`npm run verify`: структура/ссылки, Тюмень, бюджет, CHRISTINA, baseline и build. Старые команды — алиасы перенесённых тестов. Полный gate: запустить `npm run dev -- --port 3210`, затем `npm run verify:full`. Другой адрес задаётся `TEST_URL`. Браузер: `npx playwright install chromium` или `CHROME_PATH`. Playwright/pngjs и eslint-scope — только dev-зависимости; runtime не менялся.

На этой машине проверено в системном Chrome `155.0.8059.40`; Playwright работает с локальными dev-зависимостями checkout. Точная команда независимой проверки:

```bash
TEST_URL=http://127.0.0.1:3212/ CHROME_PATH='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' npm run verify:full
```

Перед запуском поднять приложение на 3212: `npm run dev -- --port 3212`. При отсутствии `CHROME_PATH` установить браузер Playwright: `npx playwright install chromium`. Песочница macOS может требовать разрешение на конкретный запуск headless Chrome и локального сервера.

`npm run test:e2e` автоматически генерирует синтетические Excel-файлы, извлекает неизменённый исходник из Git commit, указанного в `tests/parity/baseline.json`, и временно запускает его на свободном localhost-порту. В текущем браузере сначала снимаются эталоны исходника, затем в том же окружении проверяется приложение по `TEST_URL`. Сервер исходника останавливается в finally. Проверяемую текущую версию нужно поднять отдельно.

PNG, DOM-снимки, environment.json и фактические результаты скачиваний находятся только в игнорируемом `test-output/ui-baselines/run-*/`. Браузер может обновляться: исходник и текущая версия всё равно проверяются в одной версии, с одинаковыми fonts/viewport/locale/timezone. Источник эталонов всегда прежний Git commit; снимки новой реализации не подставляются как ожидаемый результат. Если история исходника отсутствует в shallow checkout, нужно получить полную историю Git.

## Baseline

`tests/parity/baseline.json` рассчитан исходным commit `1e2baa1354c40156ff8f559ad5b2f2d27e119a0e` до переноса. Сравниваются экспорты, отчёты, рекомендации, правки, цены, Тюмень с продажами и без них, Север, пересчёт, бюджет и все распакованные ZIP-части побайтно. Игнорируются только метаданные контейнера ZIP, не XML, значения, типы, формулы, стили, диапазоны, отношения или имена частей. Тюмень дополнительно проверяет неизменность входов.

E2E охватывает исходные desktop/mobile состояния четырёх режимов, заполненные отчёты и preview, бюджет apply/undo, запрет скачивания без комментария, оба северных файла после правки и подавление устаревшего результата склада при смене файла/бренда. Все имена и ZIP-части сравниваются с исходником. Ожидания скачиваний регистрируются до клика; подменённый File.arrayBuffer управляется явным release, а не sleep.

Для каждого screenshot точно сравниваются DOM-тексты, классы, геометрия, radii, значения, hidden/disabled/checked и имена скачиваний. RGBA сравниваются без масок. Допустим только ранее измеренный raster-шум на реальном геометрическом периметре округлённых элементов/нативных checkbox: максимум 100 отличающихся пикселей, компонента до 12, delta до 16; не больше двух граничных пикселей могут иметь delta до 48. Текст и внутренние области не подпадают под допуск. HTML/CSS также защищены SHA.

При необходимости повторные пары: `BASELINE_URL=http://127.0.0.1:3213/ TEST_URL=http://127.0.0.1:3212/ CHROME_PATH=... node scripts/verify-ui-repeats.mjs`. Для baseline-self дополнительно запустить исходник на 3213. Каждая пара заново получает локальные эталоны из исходника; логи сохраняются только в игнорируемом test-output. Обычного test:e2e достаточно без нерешённых расхождений.

Fixtures синтетические и создаются `scripts/prepare-fixtures.mjs` в игнорируемом `tests/fixtures/input/`; бинарные Excel-книги в Git не хранятся. `Macros.xlsm` содержит непрозрачный синтетический macro-сегмент/customXml для проверки сохранности ZIP. Это не полная проверка исполняемых реальных макросов или Excel-приложения. `tests/integration/legacy-input.mjs` генерирует BIFF8 XLS и сравнивает конвертацию, явный ноль и отказ запрещённого legacy-бланка с loader из исходного commit; XLSX/XLSM проверяются на сохранение исходного объекта bytes. Реальная legacy-книга остаётся дополнительной приватной проверкой.

`node tests/parity/replay-baseline.mjs` извлекает исходник из Git в игнорируемый test-output и воспроизводит контрольные сценарии без обновления эталонов. Workbook, бюджет и цены внедряются явно и все берутся из исходного commit; текущий check использует текущих владельцев. История baseline должна быть доступна. Capture отказывается перезаписывать baseline; расхождение требует расследования, а не обновления ожидаемого результата.

## Приватные проверки

`npm run test:private` либо `test:workbook` запускает `tests/private/workbook.mjs`, которому нужны Downloads-файлы из его списка. На baseline проверка завершилась ENOENT обязательного `агио артикул.xlsx`. Отсутствие файла — неуспех и ограничение, не зелёный пропуск. Основной gate автономен. Пользовательские книги и результаты не коммитятся.

`verify:structure` проверяет фактический граф, циклы, границы domain, внутренние импорты фасадов, SHA тел workbook-функций, неизменность HTML/CSS/Vercel, локальные ссылки и индекс документов. Исторический архив и redirect явно исключены из индекса действующих материалов.

`npm run verify` также проверяет правила .gitignore, отсутствие уже отслеживаемых служебных файлов и известные сигнатуры ключей через `scripts/verify-repository-hygiene.mjs`. Проверка не печатает значения найденных секретов.
