# Сверка алгоритмов с main

Эталон: `1e2baa1354c40156ff8f559ad5b2f2d27e119a0e`. Код браузерного прототипа не объединяется с серверной архитектурой. Excel остаётся в document-service; идентичность — в matching-service; математика — в calculation-service.

## Перенос

- Незакоммиченный бюджетный добор и опциональные остатки из рабочего каталога budget-category-stage перенесены копией; исходный каталог сохранён.
- LeviSsime: MT/числовые артикулы, русская идентичность, английское название с объёмом и объединение дублей до расчёта.
- Два склада: шаблон склада с продажами, офисный шаблон при отсутствии продаж склада, отдельные остатки и транзит, конфликтные строки для проверки.
- Режим пересчёта без бланка сохраняет фактические количества и комментарии; использует существующий экран и очередь.
- SOTHYS и NOVACUTAN: специализированные раскладки, единицы поставщика и северный экспорт.
- Выбор цен, скидки и формулы экспорта; исходная копия результата сохраняется для повторной финализации без накопления скидок. CHRISTINA сохраняет цены поставщика.
- HOME/PROFF: отдельные цены и скидки, общая или раздельные цели. Общая стоимость включает позиции без ABC; автоматический подбор не закрепляет строки как ручные правки.
- Прогноз спроса для бюджета передаётся из расчётного сервиса отдельно от среднего месячного значения.
- Округление десятичных результатов повторяет `Number(toFixed(2))`; север округляет части каждого города до суммирования. Денежные расчёты сохраняют соответствующий алгоритм main.

## Воспроизводимая проверка

Синтетические JSON-эталоны получены исполнением функций указанного коммита main и не содержат коммерческих книг:

| Набор | Сценариев |
| --- | ---: |
| Бюджет standard/fast | 80 |
| Рекомендации 7 брендов | 56 |
| Корректировка количеств | 308 |
| Север | 73 |
| Сопоставление товаров | 46 |

Дополнительно: регрессии очереди/API, факта и комментариев, экспортных формул, раскладок и интерфейса. Приватные книги подключаются только через `ORDER_FILL_PRIVATE_TESTDATA`; они не входят в Git. Сравниваются вычисления и ячейки, а не байтовое представление ZIP/OOXML.

Команды: `make verify`, `make security`, `npm run test:ui --prefix frontend`, `GOWORK=off go test -race -shuffle=on ./...` в затронутых модулях.
