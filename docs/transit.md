# Товар в пути

Режим только для ANGIOPHARM. Менеджер загружает актуальную таблицу и один или несколько оплаченных счетов PDF либо Excel (.xlsx, .xlsm, .xls). Оплата не проверяется автоматически.

PDF: текстовые счета с табличными колонками артикула, названия и количества; сканы без текстового слоя не распознаются. Excel: листы с заголовками «Артикул», «Наименование/Товар» и «Количество/Кол-во/Заказ». Нераспознанные структуры останавливают обработку. Количество позиций PDF сверяется с напечатанным итогом, если он найден.

Повторные файлы блокируются по SHA-256. Если распознан номер и дата счёта, повтор блокируется также между форматами. При отсутствии распознаваемого номера нельзя гарантировать обнаружение копий одного счёта, сохранённых в разных форматах.

Количество суммируется по артикулу из всех счетов. Сопоставление дополнительно проверяет название и объём; при наличии пары ЧЗ/не ЧЗ выбирается только ЧЗ. Несовместимые названия одного артикула в разных счетах требуют ручной проверки. Для товаров без артикула допускается однозначное соответствие по нормализованному названию. Автоматическая привязка SM60 к строке «АН Пробник» согласована пользователем ранее.

Перед выгрузкой можно изменить количество и назначить строку таблицы вручную. Назначение двух разных позиций одной строке запрещено. Несопоставленные товары выгружаются отдельно; основной файл требует подтверждения, что они не включены.

Выгрузка заменяет весь предыдущий снимок колонки «В пути»: все товарные строки сначала обнуляются, затем записываются сопоставленные количества. Строка итога обновляется. Остатки, продажи, рекомендации, факт заказа и комментарии не меняются. Исходный файл не изменяется. Макроформат .xlsm сохраняется.

Проверки: `node scripts/test-transit.mjs`, браузерный сценарий `tests/e2e/transit.mjs` в рабочей тестовой копии. Нельзя считать произвольный новый формат поставщика поддерживаемым без проверки: при неясном распознавании менеджер должен сверить предварительный список со счётом.
