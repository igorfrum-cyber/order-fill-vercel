# Карта экранов для exploratory QA

Это не сценарий. Агент сам выбирает порядок и краевые пути.
Актуальные пути — `frontend/src/features/app/routes.js`.

## Без сессии

- `/` — форма входа (логин, пароль ≥10 символов, passkey если браузер умеет)
- `/overview`, `/jobs`, `/users`, `/account` — ожидается экран входа
- `/c/<slug>` — логин компании; неизвестный slug всё ещё показывает форму
- `/invite/<token>` — одноразовый bootstrap из логов identity-service

## С сессией (роль зависит от учётки)


| Путь                              | Кто обычно                     | Что смотреть                               |
| --------------------------------- | ------------------------------ | ------------------------------------------ |
| `/overview`                       | platform_admin                 | сводка, битые виджеты, пустые данные       |
| `/jobs`, `/jobs/new`, `/jobs/:id` | purchaser / company_*          | загрузка Excel, бюджет, превью, скачивание |
| `/north`                          | не platform_admin              | склад Севера, города, перемещения          |
| `/company`                        | company_owner / admin          | реквизиты заказа, slug, логотип            |
| `/users`                          | admin/owner                    | invite, роли, disable                      |
| `/account`                        | все                            | пароль, 2FA, passkey, сессии               |
| `/companies`                      | platform_admin                 | список компаний                            |
| `/brand-rules`                    | platform_admin                 | правила брендов                            |
| `/inbound`                        | platform_admin / company_owner | входящая почта 1С                          |
| `/queue`                          | по роли                        | очередь                                    |




## Края, которые стоит трогать самим

- Короткий пароль, пустой логин, повторный submit
- Обновление страницы и кнопка «назад»
- Несуществующий `/jobs/no-such-id` и неизвестный путь
- Viewport ~390px и ~1280px
- Console + network после каждого перехода
- Загрузка файла неверного типа, если добрался до заказа
